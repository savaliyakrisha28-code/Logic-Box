## 📌 PROJECT DESCRIPTION

**Pattern Generator and Number Analyzer** is a beginner-friendly, menu-driven Python console application. It helps users generate star patterns, analyze numbers within a given range, identify Even and Odd numbers, and calculate the sum of all numbers.

This project is created as a Python Practical Assignment to improve programming logic and understand basic Python concepts.

---

## 🎯 PROJECT OBJECTIVES

- Understand Python programming fundamentals.
- Practice `for` and `while` loops.
- Generate star patterns using string multiplication.
- Check Even and Odd numbers using the modulus operator.
- Calculate the sum of numbers in a given range.
- Develop logical thinking through a menu-driven program.

---

## ✨ FEATURES

### ⭐ 1. Generate Pattern

- Accepts the number of rows from the user.
- Generates a right-angled star pattern.
- Uses `for` loop and string multiplication.

**Example:**

```text
*
**
***
****
*****
```

### 🔍 2. Number Analyzer

- Accepts starting and ending numbers.
- Checks whether each number is Even or Odd.
- Calculates the total sum of all numbers.
- Includes both starting and ending values in the range.

### 🚪 3. Exit

- Allows users to exit the application.
- Uses the `break` statement to stop the loop.

### ⚠️ 4. Invalid Choice

- Displays an error message when the user enters an invalid menu option.
- Guides the user to select options from `1` to `3`.

## 🧠 PROGRAM LOGIC

The program uses a continuous `while` loop to display the menu.

- If the user selects `1`, a star pattern is generated.
- If the user selects `2`, numbers are analyzed and their sum is calculated.
- If the user selects `3`, the program exits.
- For any other choice, an invalid choice message is displayed.
